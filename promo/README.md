# Berth promo videos

Four YouTube ads for Berth, rendered from code. Every frame is a pure function of time, so the
whole thing is reproducible and every sound lands on the frame it belongs to.

| File | Length | Style |
| --- | --- | --- |
| `Berth_A_Hype_30s.mp4` | 30s | Kinetic type, 128 BPM electronic score, no voice |
| `Berth_A_Hype_60s.mp4` | 60s | Same, adds the architecture, sites and full feature tour |
| `Berth_B_Harbor_30s.mp4` | 30s | Cinematic, voiceover, 96 BPM score, logo as a harbor at night |
| `Berth_B_Harbor_60s.mp4` | 60s | Same, with the four step walkthrough and every line voiced |

Output: 1920x1080, 60 fps, H.264 High, BT.709, AAC 320k 48 kHz, -14 LUFS (YouTube's target).

## Build

```sh
./build.sh              # all four, about 40 minutes on 4 cores
./build.sh a30          # one variant
node still.mjs a60 12.5,30 out/stills   # preview single frames
```

Needs Node with Playwright (Chromium), Python 3 with numpy, scipy, soundfile, pyloudnorm and
kokoro-onnx, and an ffmpeg with libx264. The Kokoro model files go in `/home/user/tts`
(or set `KOKORO_DIR`).

## Layout

- `src/engine.js` timeline, seek, WebGL background (aurora, grid floor, warp, harbor water)
- `src/kit.js` shared scenes: ignite, word slam, lockup, terminal, architecture, bento, sites, showcase, pricing, end card
- `src/scenes-a.js`, `src/scenes-b.js` the two variations, their scene lengths and music form
- `audio/score.py` the score and all sound effects, synthesized in numpy from the page's cue list
- `audio/vo.py` voiceover lines (Kokoro, voice `af_heart`)
- `render.mjs` parallel frame capture, `meta.mjs` timeline export, `build.sh` the pipeline

Copy, commands and prices come from atberth.com and the berth CLI README. To change a line of
copy, edit the scene file and rebuild. To change a voice line, edit `TEXT` in `scenes-b.js`,
delete `out/vo`, and rebuild.
